# 🧩 Sudoku Solver (Tkinter GUI)

## 📌 Overview

This project is a **Sudoku Solver application with a graphical user interface (GUI)** built using **Python and Tkinter**. It allows users to input a Sudoku puzzle and automatically solves it using a backtracking algorithm.

The goal of this project is to combine **algorithmic problem-solving** with a **simple and interactive UI**, making it easy for users to visualize the solution process.

---

## 🚀 Features

* 🖥️ User-friendly GUI using Tkinter
* ✍️ Manual input of Sudoku puzzle
* ⚡ Fast and efficient solving using backtracking
* 🔄 Displays solved Sudoku instantly
* ❌ Handles invalid or unsolvable inputs

---

## 🛠️ Technologies Used

* **Python**
* **Tkinter (for GUI)**
* **Backtracking Algorithm**

## ▶️ How to Run
